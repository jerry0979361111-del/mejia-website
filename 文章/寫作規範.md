# SEO 文章自動撰寫與月報規範

每週一、四的「撰寫發布」與每月 3 號的「SEO 月報」排程都照這份規範執行。改規則直接改這份檔案。

## 素材來源（依序）
1. Notion「美家官網 SEO 文章中心」→「文章素材」資料庫（data source `collection://424c06cd-5889-8108-be8c-000b03ede65f`）中狀態為「待撰寫」的項目，從最早建立的開始。
2. 沒有待撰寫素材時，取 `文章/主題清單.md` 最上面還沒打勾的主題。
3. 兩者都沒有時，寫最新的澳洲房市／政策新聞分析（每週最多一篇）。
- 每次執行寫 1 篇。寫完把 Notion 狀態改成「已發布」，填「文章網址」「發布日期」；主題清單的項目打勾 [x] 並附檔名。

## 事實查核（不通過就不發布）
- 政策、稅率、印花稅、FIRB、簽證、利率、房價數字：一定要找到官方或一手來源（ATO、FIRB／foreigninvestment.gov.au、各州稅務局 Revenue NSW／SRO VIC／QRO、RBA、ABS、Home Affairs、Cotality 月報），並列在「參考來源」。
- 找不到來源或來源互相矛盾：不發布，Notion 狀態改「需補資料」，在「備註」寫明缺什麼；主題清單則在該行後面註記原因。
- 政策只寫「已公布／已立法」的實際狀態，不要把「擬議」寫成「已生效」。
- 建案資訊只用網站上的資料（`src/data/projects.generated.json`），不寫內部資料（價格帶、競品比較、銷售輔助）。
- **禁止公開的建案（`worker/hidden-projects.json`）絕對不能出現在文章任何地方。**
- 不承諾報酬率、增值或保證出租；投資相關一律提醒以專業人士意見為準。

## 寫法
- 繁體中文、台灣用語、全形標點；不要簡體字。字數 1,500–2,500 字。
- 開頭 2–3 句直接回答讀者的問題（給 Google 摘要與 AI 搜尋引用）。
- 用 `##`／`###` 小標分段，善用條列與表格；文末加「常見問題」3–5 題。
- 每篇至少 3 個站內連結：相關建案頁（`/projects/<slug>/`）、城市頁（`/cities/<city>/`）、試算工具（`/calculator/`）、購房流程（`/process/`）、FAQ 或其他文章。
- 加入美家的觀點或實務經驗（顧問專長、常見客戶情境），不要只是整理新聞。
- 標題 30 字內、含主要關鍵字；摘要 80–120 字。

## 檔案格式（`文章/YYYY-MM-DD-英文-slug.md`）
```
---
標題: "…"
狀態: 已核准
分類: 市場觀點｜買家指南｜政策稅務｜建案動態｜城市生活
摘要: "…"
發布日期: YYYY-MM-DD
作者: 顧問 slug（見下表）
相關建案: [slug1, slug2]   # 選填，文末會顯示建案卡片
封面照: 檔名.jpg            # 選填，放在 文章/圖片/
參考來源:
  - 名稱: "…"
    網址: https://…
---
```
- 修改既有文章內容時，加上或更新 `更新日期: YYYY-MM-DD`。

## 發布步驟
1. 寫好檔案後執行 `npm run build`，確認建置成功、新文章頁存在、沒有禁止公開建案名稱。
2. commit 並 push 到 main（GitHub Actions 自動部署），等正式站 `https://mejia.au/insights/<slug>/` 回應 200。
3. 更新 Notion「文章素材」或主題清單。

## 每月 SEO 月報（每月 3 號）
1. 數據：Google Search Console（曝光、點擊、平均排名、各頁與查詢字詞）、GA4（文章瀏覽、`generate_lead` 名單、`search` 站內搜尋）、D1 `leads`（來源頁面）、D1 `chat_log`（AI 顧問提問，找內容缺口）。拿不到的數據在月報中註明。
2. 直接執行優化（每月 3–8 項）：
   - 曝光高、點擊率低：改標題與摘要。
   - 排名 8–20 名：補充內容、加常見問題、加內部連結，填 `更新日期`。
   - 有提問但網站沒內容：加入主題清單（排在最前面）。
   - 過時的數字或政策：更新並附來源。
   - 沒流量的舊文：合併或補強。
3. 月報寫到 Notion「SEO 月報」（data source `collection://424c06cd-5889-81d3-b865-000beff5f709`），內容：成效數字與前月比較、本月發布文章、已執行的優化（含網址）、下月計畫與建議。
4. 用 Gmail 寄月報摘要與 Notion 連結給 jerry0979361111@gmail.com、admin@mejia.au。
