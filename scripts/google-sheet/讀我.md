# 官網名單 → Google 試算表＋Gmail 通知

官網每收到一筆表單名單：先存進 Cloudflare D1（備份）→ 送到這份 Google 試算表新增一列 → 用你的 Gmail 寄通知信。

## 安裝（約 5 分鐘，只要做一次）
1. 用要寄通知信的 Google 帳號（例如 jerry0979361111@gmail.com）開一份新的 Google 試算表，命名為「Mejia 官網名單」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的程式全部刪掉，貼上同資料夾的「名單收件.gs」全部內容，按儲存（磁碟片圖示）。
4. 上方函式選單選「初始化」→ 按「執行」。
   - 第一次會跳出授權視窗：選你的帳號 →「進階」→「前往（不安全）」→「允許」。（這是你自己的程式，Google 對未經審核的程式都會這樣提示）
   - 完成後試算表會多出「名單」和「設定」兩個分頁，你的信箱會收到一封測試信。
5. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 說明：官網名單
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（https://script.google.com/macros/s/…/exec）。
6. 把網址設定到 Cloudflare（**不要貼在對話或公開的地方**，網址本身就等於通行碼）：
   Cloudflare 後台 → Workers & Pages → mejia-website → 設定（Settings）→ 變數和秘密（Variables and Secrets）→ 新增 → 類型選「秘密（Secret）」，名稱 `SHEET_WEBHOOK_URL`，值貼上網址 → 部署。

## 日常使用
- 改收件人：改「設定」分頁 B1，多個信箱用逗號分隔。
- 「聯絡狀態」「負責顧問」「備註」欄位給業務填寫追蹤。
- 程式更新後要重新部署：「部署」→「管理部署作業」→ 編輯（鉛筆）→ 版本選「新版本」→ 部署（網址不變）。

## 確認有沒有送到
Cloudflare 後台 → 儲存空間與資料庫 → D1 → mejia-leads → 主控台，執行：
`SELECT id, created_at, name, sheet_sent, email_sent, line_sent FROM leads ORDER BY id DESC;`
`sheet_sent = 1` 代表已送到試算表（也已觸發 Gmail 通知）。（需先套用 migrations/0002_sheet_sent.sql）

## 注意
- 一般 Gmail 帳號每天最多寄 100 封（Google Workspace 帳號 1,500 封）。
- 試算表沒收到時，名單仍保存在 D1，不會遺失。
